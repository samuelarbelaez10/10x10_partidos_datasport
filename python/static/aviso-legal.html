2. Objeto del sitio web

Data Games es una plataforma SaaS para la digitalización del deporte estudiantil: permite a colegios, federaciones y organizadores gestionar torneos multideporte con marcadores en vivo, estadísticas profesionales y acceso público vía QR.

El acceso al sitio web es gratuito; algunas funcionalidades —como la creación de torneos, la gestión de partidos en vivo y la carga masiva de equipos— están sujetas a contratación previa de un plan comercial.
